# I2 Gemini CLI Adapter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Gemini CLI 0.67.0 runs as a qualified container-confined harness from the bundle's private Node, with API-key access only through a runner-held loopback proxy and a refreshable `oauth_creds.json` subscription login.

**Architecture:** A pure recipe (`adapter/gemini.rs`) mirrors `adapter/claude.rs`. `GeminiAgentHome` writes a private `GEMINI_CLI_HOME` whose system settings outrank workspace settings. `GeminiApiProxy` mirrors `AqApiProxy`: it swaps a local capability in `x-goog-api-key` for the runner-held key and allows only the generative endpoints. `subscription_login.rs` gains a `GeminiOauthCreds` kind compared on `expiry_date`. The bundle ships the npm tarball under `/opt/aq/harnesses/gemini` with a wrapper that runs `/opt/aq/node/bin/node`.

**Tech Stack:** Rust (tokio, reqwest), Python packaging scripts, Podman/Docker live tests.

**Spec:** task azure-horizon-22.5 description; 0005 §8.3 (rows recorded in docs/implementation/I2.md, not edited).

## Global Constraints
- Pin `@google/gemini-cli` 0.67.0; tarball sha512 `lDJfCcYem6/6QZdwZFiGfOu1ZxJJ+j4wsr4HlmcYBfqUHTDXLKDv1MPUXYL2Ok1ygdfMve0F5KrW/ORNZRSHIg==`.
- Executable is `/opt/aq/node/bin/node /opt/aq/harnesses/gemini/bundle/gemini.js` (never project Node).
- Confinement: container only. Native is refused, because Gemini's `--sandbox` needs docker/podman or macOS sandbox-exec.
- Provider key never enters the sandbox (SBX7); the subscription credential is a file (SBX19).
- Recording format is `gemini-recording-jsonl-6814e00` at `$GEMINI_CLI_HOME/.gemini/tmp/<project>/chats/session-*.jsonl`.

## Review Focus
- A workspace `.gemini/settings.json` that tries to re-enable hooks or switch the auth type must lose to the system settings (test: recipe sets `GEMINI_CLI_SYSTEM_SETTINGS_PATH`).
- A proxy request with a wrong or missing `x-goog-api-key` must be refused before any upstream call.
- A proxy path outside `/v1beta/models/<m>:(streamGenerateContent|generateContent|countTokens)` must be refused.
- An oauth_creds.json with an unchanged or older `expiry_date` must be retained, not written back.
- Native mode must be refused even if the manifest declares it.
