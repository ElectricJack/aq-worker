### Live test (`crates/aq-worker/tests/gemini_live.rs`)

It follows `claude_live.rs`, with `Controller<Shared, Lease>` driving the real `DockerLocalBackend`. The runner script is rendered from the library recipe (`GeminiAgentHome::install`), so argv, env and settings are the adapter's own. The credential reaches the sandbox only as controller-delivered private material.

- **API key:** the runner moves the material into a 0600 file in a 0700 dir and starts `aq-worker-test-support gemini-proxy`. It deletes the key file once the proxy is ready, and exports only `GOOGLE_GEMINI_BASE_URL=<proxy>` and `GEMINI_API_KEY=<capability>` to a clean environment. The leak scan pattern comes from a pipe.
- **Subscription:** the runner installs `.gemini/oauth_creds.json`. The host reads it back before destroy and writes it back atomically only if it changed. The leak scan allows the refresh token only in that file.
- **Both modes:** the run fixes the bug in a red `cargo test` crate, checks the fix, and publishes to a bare repo. The run must also leave one native recording, which is fed to the shipped `gemini-recording-jsonl-6814e00` reader.

**Env:** `AQ_DOCKER_LOCAL_SOCKET`, `AQ_DOCKER_LOCAL_SHARED_ROOT_FS=1`, `AQ_GEMINI_LIVE_IMAGE` (the digest above), `AQ_GEMINI_LIVE_KEY_FILE`, `AQ_GEMINI_LIVE_OAUTH_CREDS_FILE`, `AQ_GEMINI_LIVE_MODEL` (default `gemini-2.5-flash`), and `AQ_GEMINI_LIVE_EVIDENCE_DIR`.

## Limits and follow-ups

- **Live qualification:** blocked on owner credentials, as above.
- **Shared uid:** on this single-UID sandbox Podman, the runner, the proxy and the CLI all run as uid 0, so in this test the proxy's key memory is not uid-separated from the agent. Production separation is B6a2 (distinct agent uid).
- **System settings ownership (B6a2):** the CLI accepts system settings only from a root-owned, non-group/other-writable file and parent directory. Today `GeminiAgentHome` writes `system-settings.json` inside the agent home, which works only while the runner is root and the home is root-owned. Follow-up: move it to a runner-owned directory outside the agent home.
- **0005 §8.3:** the rows above need adding to aq-server 0005 (docs follow-up).
- **aq-server:** the `gemini-oauth-creds` login kind and the operator import (cross-repo follow-up).
- **Template admission:** the derived image, like `rust-1`, is unadmitted until the C3c scanner works on this host.
