The success case fetches the exported base over HTTP, verifies/imports it, launches the fixture, checkpoints/uploads/imports centrally, recovers an intermediary 502 after the result committed, and retires only after explicit release. The first bundle download response is deliberately held after the manifest has been stored while control polls continue with zero slots; no second attempt is admitted. The cancellation case delivers and acknowledges Cancel while that response is held, then proves no bundle bytes are accepted past the canceled boundary, no import/create/launch occurs and no result is invented.

This proves restart convergence without reacquiring execution authority; immediate inline canceled-result convergence remains outside this change. The HTTP peers mirror selected public daemon rules but are not live daemon authorization/DB qualification. No production harness, provider, fleet or throughput claim follows.
