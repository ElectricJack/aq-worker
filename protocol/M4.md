# Execution 2 optional source and graph contracts (package 0.2.0)

`ExecutionSpec.bindings` is optional, omitted when absent, and included in the frozen specification digest when present. This preserves existing execution-2 fixture digest bytes and foundation protocol 1 unchanged. Graph-only bindings do not require a source repository. Unknown required capabilities are refused. Empty bindings are rejected. Graph binding requires `scoped-agent-access-v1`; resumable transfer separately negotiates `source-transfer-v1`. A source binding requires negotiated `source-workspaces-v1`; no deployed worker driver advertises that capability until its local adapter is configured.

`GraphBinding.workspace_id` maps to agent-access-1 workspace; the existing specification project UUID supplies project identity. `profile_id`, positive canonical signed-64 decimal `profile_revision`, `profile_digest`, and `context_digest` freeze the exact API01 profile and launch snapshot. Credential values and references are absent. These labels are equality assertions, never authorization.

`SourceBinding` freezes repository UUID, positive binding generation, logical identity and exact typed SHA1 base OID. The initial supported aq-git profile rejects unsupported repository features. Transfer manifests freeze the attempt/generation, resolved-spec digest, source binding, source role (`base` or `checkpoint`), exact checkpoint OID and artifact UUID. Base transfers must use the frozen base as checkpoint; checkpoint transfers name an explicit retained source. Authenticated transport must compare all fields against server-owned assignment state.

`TransferManifest.manifest_digest` is SHA256 of the exact transferred manifest file bytes. Bundle digest likewise covers exact bytes. `TransferChunkRequest` is a descriptor for a raw bounded HTTP body, never a JSON byte array. Offsets/lengths are checked against the frozen file size; identical chunk IDs bind descriptor and exact bytes. Status describes bytes durably staged, not source retention. Finalization validates both complete files before publishing the incoming artifact directory and importing through aq-git's public interface with a durable stable operation ID.

`CentralRetentionReceipt.manifest_digest` is aq-git's canonical typed-manifest digest, which may differ from the transported pretty JSON file digest. Verify the canonical manifest mapping independently. A receipt binds the authenticated transfer, repository generation, exact retained source OID and central aq-git retention handle. Upload completion, a report disposition and central retained source are separate facts. An arbitrary receipt UUID never authorizes cleanup: local runtime verifies transfer/manifest/source association and central retention release before retirement.

Types and validation in `aq-worker-protocol/src/m4.rs` are normative; generated schema includes the public messages. Package 0.1.1 remains a historical release; this is the new 0.2.0 candidate, not an in-place mutation of the published artifact.
